# 音のC/D比デモ（疑似重量感プロトタイプ）

手の高さ h [cm] に応じて音高を Δp = ±g·h [半音] だけ変える実験用プロトタイプ（正弦波）。

https://eisuke29.github.io/sound-cd-weight/ （`#demo` で自動デモ）

## 画面の読み方

- 青の箱＝手の高さ（左のものさし、cm）。橙の音符＝音の高さ（右の鍵盤、1段＝1半音）
- 2つをつなぐ弦は、鳴ると揺れ、音が高いほど波が細かい
- 点線の箱と矢印＝次に動かす先（30 cm）。鍵盤の右のつまみ＝点線まで上げたときに音が届くところ（上下に動かすとゲイン g が変わる）
- 下のカード＝ゲインの5段階。箱はどれも同じだけ上がり、音の上がり方だけが違う
- 「?」＝ゲインを隠して選ぶ。隠れている間にカード（または 1–5）を選ぶと答え合わせ

箱の見た目と動きはゲインによらず同じ（変わるのは音だけ）。

## 動かし方

マウス／指（箱をつかむ）・カメラ（MediaPipe Hand Landmarker）・かざす（置いたスマホ、手の大きさから距離を推定）・持つ（DeviceMotion）・自動。「かざす」「持つ」はタッチ端末だけに表示。

## 設定と記録（右上のつまみの絵）

- ゲイン g：0.00–1.00 半音/cm（0.01刻み）、カード5枚の値（初期 0.05/0.1/0.2/0.4/0.8、localStorage保存）
- 向き、鳴らし方（動く間だけ／ずっと）、最初の音 f₀（220–880 Hz、初期 440）、音程の上限（±12/24/36 半音、初期 24）
- 記録：h が 5 cm 超 → 2 cm 未満に戻るまでを1回として自動記録（CSVをコピー）。隠したゲインは答えを見るまで「?」
- キー：← → カード、Shift+← → ±0.01、1–5 直接、Space 0にする、Enter 画面を隠す、R あてる、A 答え、D 向き、M 鳴らし方（値を読み上げ）

ファイルは `index.html` 1つのみ。
