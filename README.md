# 音のC/D比デモ

持ち上げる高さに合わせて音の高さが変わるWebプロトタイプです。
ゲイン（1 cmあたり何半音変わるか）を変えて、重さの感じ方が変わるかを試します。

**デモ：** https://eisuke29.github.io/sound-cd-weight/

## 測り方

- **カメラ**（PC・スマホ両方、おすすめ）：カメラで手を検出。スマホは立てて置き、前／後ろのカメラを切り替え可（MediaPipe Hand Landmarker）。手のひらの大きさを約9.5 cmとしてcmに換算
- **置いたスマホ**：スマホを画面を上にして机に置き、上を向いたカメラで手を写す。写った手の大きさ（画面上）と手の実寸の形（MediaPipeのworld landmarks）を比べて距離を出す。画角は約70度と仮定
- **センサー**（スマホ）：加速度センサーから推定。下に動いて止まったら机に戻ったとみなして0に戻す。精度は粗い

## できること

- ゲイン5段階：0.05／0.1／0.2／0.4／0.8 半音/cm（誇張した値）
- 向き：上げると音が上がる／下がる
- 鳴らし方：動く間だけ／ずっと
- 目を閉じるボタン（画面を隠す）
- 最初の音は 440 Hz で固定。正弦波、音量一定

ファイルは `index.html` 1つだけです。
