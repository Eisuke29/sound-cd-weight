# 音のC/D比デモ

スマホを机から持ち上げると、高さに合わせて音の高さが変わるWebプロトタイプです。
ゲイン（1 cmあたり何半音変わるか）を変えて、重さの感じ方が変わるかを試します。

**デモ：** https://eisuke29.github.io/sound-cd-weight/

## できること

- ゲイン5段階：0.05／0.1／0.2（標準）／0.4／0.8 半音/cm（誇張した値）
- 向き：上げると音が上がる／下がる
- 鳴らし方：動いている間だけ／ずっと鳴らす
- 最初の音は 440 Hz で固定。音は正弦波、音量は一定
- PC向けにスライダーで高さを動かすシミュレーション

## 使い方

1. スマホを画面を上にして机に置き、「スタート」を押す（iPhoneは動きの許可が必要）
2. 有線イヤホン推奨。iPhoneはマナーモードを解除
3. 1〜2秒かけて20〜30 cm持ち上げ、止めて、机に戻す
4. 机に置いてじっとさせると高さが0に戻る。ずれたら「今の高さを0にする」

## しくみ

高さは加速度センサーから推定しています（重力の向きへの加速度を2回積分）。
誤差がたまらないように、止まったら速さを0に、机の上で静止したら高さを0に戻します。
数cmの誤差があるので、実験用ではなく体験用のプロトタイプです。

ファイルは `index.html` 1つだけです。
