# 音のC/D比デモ（疑似重量感プロトタイプ）

手の高さ h [cm] に応じて音高を Δp = ±g·h [半音] だけ変える実験用プロトタイプ（正弦波）。1画面に収まるコンパクトUI。

https://eisuke29.github.io/sound-cd-weight/ 

- 測り方：カメラ（MediaPipe Hand Landmarker）／置いたスマホ（手の大きさから距離を推定）／センサー（DeviceMotion）
- ゲイン g：スライダー＋数値（0.00–1.00 半音/cm、0.01刻み）、プリセット5つ（初期 0.05/0.1/0.2/0.4/0.8、「プリセット編集」で変更・localStorage保存）
- 基準の音 f₀：220/330/440/660/880 Hz（初期 440）、音程の上限：±12/24/36 半音（初期 24、メーターの目盛りも連動）
- 向き（上げると高く／低く）、鳴らし方（動く間／ずっと）、目を閉じる
- 0に合わせる：メーターの下のボタン（2秒待ってから）または Space（すぐ）。手が止まったところが0になる。手が0より下にいる状態が続くとボタンが光る
- 記録：h が 5 cm 超 → 2 cm 未満に戻るまでを1回として自動記録（CSVをコピー）。ランダムゲイン中は g を「?」で隠し、A で開示
- キー：← → プリセット、Shift+← → ±0.01、1–5 直接、Space 0に合わせる、Enter 目を閉じる、R ランダム（非表示）、A 答え、D 向き、M 鳴らし方（音声で値を読み上げ）

ファイルは `index.html` 1つのみ。
